MoleSignal Helm charts

Helm charts for MoleSignal, self-hosted, OpenTelemetry-native observability.

Add the repository

helm repo add molesignal https://charts.molesignal.com
helm repo update

Charts

ChartDeploys
molesignal MoleSignal itself, as one pod or as separate router, intake, querier, compactor and alert workloads, with an optional bundled PostgreSQL and RustFS for evaluation.
probe-agent Probe Agents, which run synthetic checks from a private location and connect to a MoleSignal server, in the same cluster or elsewhere.

Try it out

One MoleSignal pod plus a bundled PostgreSQL and RustFS:

helm install molesignal molesignal/molesignal --namespace molesignal --create-namespace
kubectl --namespace molesignal port-forward svc/molesignal 5080:5080

Then open http://127.0.0.1:5080. For production, follow the deployment guide.

Other addresses

The same charts are published as OCI artifacts at oci://ghcr.io/molesignal/charts/<chart>. Helm reads this repository through index.yaml.
